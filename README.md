SAWS
====

> [!WARNING]
> **SAWS (Stand Alone Web Service framework) was archived on 17 November 2026.** It is no longer maintained or supported.
>
> SOAP is no longer widely used for web services. We recommend [Jarvis](https://github.com/Dyalog/Jarvis) for JSON or REST services, or the experimental [Stark](https://github.com/dyalog-labs/stark), which builds on Jarvis's REST paradigm and generates OpenAPI specifications, a modern counterpart to WSDL.
